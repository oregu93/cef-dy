# Локальное развёртывание и multi-machine workflow

## Контекст

Knowledge Base v2.1 подготовлена к использованию вне ChatGPT. Требуется
обеспечить работу с одного проекта на рабочем компьютере и ноутбуке.

## Решение

Git/GitHub принят как основной механизм истории и синхронизации текстового
слоя, кода и небольших reproducibility artifacts.

Большие raw/private данные хранятся вне Git и привязываются через
`dataset_id` и локальный `configs/local_paths.yaml`.

Yandex.Disk может использоваться для внешних данных и резервного
копирования, но не как независимая система истории Git-репозитория.

## Следующий шаг

Развернуть Knowledge Base на рабочем компьютере, проверить Obsidian vault,
инициализировать Git и выполнить первый безопасный commit.
