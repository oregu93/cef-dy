# Results

В Git следует хранить только небольшие итоговые таблицы и рисунки, необходимые для воспроизводимости и публикации. Крупные промежуточные результаты оптимизации и необработанные данные следует хранить во внешнем `CEF_Dy_Data/`.

Крупные артефакты воспроизводимости, необходимые для воспроизведения результата, могут храниться во внешнем `CEF_Dy_Data`, если отслеживаемый checkpoint или provenance явно содержит их логический внешний путь, размер в байтах и SHA-256. Отсутствие крупного файла непосредственно в Git в таком случае не означает отсутствия канонического provenance.
